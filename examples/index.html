plotagents

Gráficos bellos con una sola llamada. Un objeto JSON con datos y nombres de campos entra; sale un SVG accesible, con buena tipografía, colores validados para daltonismo y tooltips. Diseñado para que un agente de IA lo use sin pensar en diseño.

npm install plotagents

Columnas

Pocas categorías cortas → columnas, ordenadas de mayor a menor, con el valor en la punta y sin eje (los valores ya están escritos).

Ver código
plot({
  type: "bar",
  title: "Biobío concentra el 30% de las ventas del sur",
  subtitle: "Ventas por región, millones de pesos, 2025",
  source: "datos ilustrativos",
  data: [
    {region: "Biobío", ventas: 1240},
    {region: "Araucanía", ventas: 880},
    // … 4 filas más
  ],
  x: "region",
  y: "ventas"
})

Barras horizontales con foco

Etiquetas largas → barras horizontales automáticamente. highlight destaca una categoría y atenúa el resto.

Ver código
plot({
  type: "bar",
  title: "Casi tres de cada diez reclamos son por retrasos en la entrega",
  subtitle: "Reclamos recibidos por motivo, enero a junio",
  source: "datos ilustrativos",
  data: [
    {servicio: "Retraso en la entrega del pedido", casos: 412},
    {servicio: "Cobro duplicado en la tarjeta", casos: 268},
    // … 5 filas más
  ],
  x: "servicio",
  y: "casos",
  highlight: "Retraso en la entrega del pedido"
})

Barras agrupadas

Una serie por color, en orden fijo. Con 2+ series la leyenda siempre está presente.

Ver código
plot({
  type: "bar",
  title: "En 2025 el canal online superó por primera vez a la tienda",
  subtitle: "Ventas por canal, millones de pesos",
  source: "datos ilustrativos",
  data: [
    {"año":2022, canal: "Tienda", ventas: 820},
    {"año":2022, canal: "Online", ventas: 310},
    // … 10 filas más
  ],
  x: "año",
  y: "ventas",
  series: "canal"
})

Apiladas al 100%

Líneas con anotación

Fechas "YYYY-MM" se detectan solas. Etiquetas directas al final de cada línea y anotaciones de eventos.

Ver código
plot({
  type: "line",
  title: "Ñuble acelera desde la apertura de su nueva sucursal",
  subtitle: "Ventas mensuales por región, millones de pesos",
  source: "datos ilustrativos",
  data: [
    {mes: "2022-01", region: "Biobío", ventas: 123},
    {mes: "2022-01", region: "Araucanía", ventas: 81},
    // … 142 filas más
  ],
  x: "mes",
  y: "ventas",
  series: "region",
  annotations: [
    {
      x: "2024-01",
      label: "Nueva sucursal en Chillán"
    }
  ]
})

Índice base 100 (sin doble eje)

Medidas de escalas distintas no van en dos ejes: index: true las lleva a base 100 y se comparan crecimientos.

Ver código
plot({
  type: "line",
  title: "Los clientes crecieron 2,4 veces; la dotación, solo 7%",
  subtitle: "Índice 2018 = 100",
  source: "datos ilustrativos",
  data: [
    {"año":2018, ingresos: 1180, dotacion: 212, clientes: 3100},
    {"año":2019, ingresos: 1260, dotacion: 220, clientes: 3400},
    // … 6 filas más
  ],
  x: "año",
  y: [
    "clientes",
    "ingresos",
    "dotacion"
  ],
  labelsFor: {
    dotacion: "Dotación"
  },
  index: true,
  refLines: [
    {
      y: 100,
      label: "Base"
    }
  ]
})

Burbujas con tendencia

Tamaño = área proporcional a la población. Rotula solo los puntos que importan y agrega la recta de tendencia con R².

Ver código
plot({
  type: "bubble",
  title: "A mayor ingreso por persona, mayor uso de internet",
  subtitle: "PIB per cápita (miles de US$ PPA) y % de la población que usa internet",
  source: "datos ilustrativos",
  data: [
    {pais: "Chile", pib: 30.2, internet: 90.2, poblacion: 19.8, continente: "Sudamérica"},
    {pais: "Perú", pib: 16, internet: 75, poblacion: 34, continente: "Sudamérica"},
    // … 14 filas más
  ],
  x: "pib",
  y: "internet",
  size: "poblacion",
  series: "continente",
  label: "pais",
  labels: [
    "Chile",
    "Estados Unidos",
    "Brasil",
    "Alemania",
    "Bolivia",
    "México"
  ],
  xLabel: "PIB per cápita (miles US$)",
  yLabel: "Usuarios de internet (%)",
  trend: true
})

Partes de un todo con jerarquía, al estilo del Atlas de Complejidad Económica. Color por sector y participación en cada rectángulo.

Ver código

  type: "treemap",
  title: "El cobre explica más de la mitad de las exportaciones",

  source: "datos ilustrativos",
  data: [
    {sector: "Minería", producto: "Cobre", valor: 50.1},
    {sector: "Minería", producto: "Litio", valor: 6.2},
    // … 18 filas más
  ],
  path: [
    "sector",
    "producto"
  ],
  value: "valor",
  height: 480
})

Indicadores (KPI)

Cuando la historia es un número, el número es el gráfico. Variación con flecha + texto, tendencia y meta.

Ver código
plot({
  type: "kpi",
  title: "El trimestre cierra con ventas 12% sobre el año anterior",
  source: "datos ilustrativos",
  items: [
    {label: "Ventas", value: 1250000000, format: "currency", delta: 0.124, period: "vs T3 2025", trend: [8.1,8.6,8.4,9.8,10.9,12.5]},
    {label: "Clientes activos", value: 8420, delta: -0.032, period: "vs T3 2025", trend: [9,8.9,8.7,8.6,8.5,8.4]},
    {label: "Costo por cliente", value: 18500, format: "currency", delta: -0.08, good: "down", period: "vs T3 2025"},
    {label: "Satisfacción (NPS)", value: 62, target: 70, delta: 0.05, period: "vs T3 2025"}
  ]
})
